# Console-Games

<sub>Coleção de jogos em console · C# · .NET</sub>

<br/>

Repositório dedicado ao desenvolvimento de jogos utilizando **C# e .NET**, executados diretamente no console.

Cada projeto explora conceitos fundamentais de programação, lógica, estruturas de dados e organização de código por meio da implementação de jogos clássicos.
